Spelling with a Super Small Model

Use Character Tokenization with length 4. This model can only see the last 4 characters when guessing the next 1 character. That means lots of time it can't even see whole words. Even so, it does a pretty good job of spelling long words correctly. For very long words, it makes up plausible looking new words sometimes. You can see more or less made up words by setting the temperature higher up to Random or lower down to Deterministic.

✓ Complete!

Robust Generation with BPE

BPE (Byte Pair Encoding) uses a dynamic method to extract out frequently used sequences, such as "ing" and "sh", and using them as a single concept. This is more flexible than Word tokenization, because it can encode and create new words like "rerunningingly" that were not seen in the source material. But unlike Character tokenization, it encodes more information per token. Use BPE with token length 8 and train it. We can see from the message that the branching per state is low, which means the output will tend to not have much variety. But if we use "Calculate longest deterministic chain", we can see that the chains are not ridiculously long. Certainly not like Word tokenization. Now when we click "Use Random State" and then spam click "Generate (+20)", let's look at the Top 20 continuations. We can see we rarely get to a situation with 100% for just 1 continuation. This means it doesn't get stuck in a rut of copying the source material.

✓ Complete!

Play with Temperature

Try any of the above with a temperature other than the default "Reserved". What the temperature does is change how the next token is selected. The "Typical (1.0)" means to select the next token using exactly the same frequency that is observed in the source material. For example, if text is "yesterday h" and we are looking for the next character, we will see in the source material that maybe "a" appears 2 times and "i" appears once. When selecting the next character, "a" will be randomly selected 2/3 times, and "i" 1/3 times. If we change the temperature all the way down to "Deterministic (0.0)" then we will always pick the most frequent next letter, in this case "a". If we move the temperature up, then the selection becomes more even, close to even odds for all next tokens. What this feels like when you read the output text is interesting. A fun starting point is Character tokenization with length 5. Try both extremes. At what point does punctuation start to come up regularly or too much? At what point are new words invented?

✓ Complete!
